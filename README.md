# Finpulse

Нативное портативное приложение для учёта личных и деловых финансов под Windows 10/11.
Запускается без установки, полностью офлайн, файлы данных зашифрованы, один exe без внешних рантаймов.

Статус: **версия 0.1.0, первый рабочий срез MVP.** Решения: [ADR/](ADR/README.md).

## Скачать
**[Последняя версия: Finpulse.exe](https://github.com/axionode/Finpulse/releases/latest)**. Положите файл в любую папку и запустите двойным щелчком, установка не нужна.
Рядом появится папка `Finpulse Data` с вашими данными. Пошаговая инструкция на странице релиза.
Переезд на другой компьютер: Настройки → Экспорт всех данных, на новом компьютере Импорт.

## Что уже работает
- Книги (личное, кошелёк, предприятие, проект), у каждой своя валюта, цвет, иконка
- Счета внутри книги, расходы, доходы, переводы, корректировка остатка
- Категории и подкатегории с иконками, наборы по умолчанию для личного и бизнеса
- Калькулятор в поле суммы (`1200/3+45`), подсказки получателей и автокатегория
- Обзор, список операций с поиском и фильтрами, корзина на 30 дней, Ctrl+Z
- Отчёты: по категориям, денежный поток, средние значения, все периоды
- PIN из 4 цифр на книгу, задержки после неверных попыток, автоблокировка
- Шифрование каждой книги (ChaCha20-Poly1305), ключи под Argon2id / DPAPI
- Экспорт/импорт `.fpbackup` с паролем по желанию, сброс PIN при импорте, автобэкап при выходе
- Английский и русский, тёмная тема Nordic Night

## Сборка на Windows (MSVC)
Нужны Visual Studio 2022 или Build Tools 2022 с компонентом "Desktop development with C++" (включает CMake, Ninja и Windows SDK).
```
build.cmd           собрать Release в dist\Finpulse.exe
build.cmd Debug     отладочная сборка
```

## Сборка на Linux (кросс-компиляция MinGW-w64)
```
sudo apt install g++-mingw-w64-x86-64-posix cmake ninja-build
./build.sh          dist/Finpulse.exe + проверка, что exe не импортирует сетевых библиотек
```

## Тесты
`build/<cfg>/finpulse_tests.exe` (или `build/mingw/finpulse_tests.exe`). Пишет результат в `test-results.txt` рядом с собой.
Тесты дат, сумм и калькулятора собираются и на Linux: `g++ -std=c++20 -Isrc tests/tests.cpp src/core/*.cpp -o core_tests`.

## Для ИИ-агента
1. Прочитай `ADR/README.md` и ADR-0018 (отличия реализации от первых решений).
2. Код: `src/core` (без Windows), `src/crypto`, `src/storage`, `src/services` (библиотека `fpcore`), `src/ui` (рендер и виджеты), `src/app` (экраны, диалоги, `main.cpp`).
3. Сетевые API запрещены (ADR-0008). Сборка падает, если exe импортирует ws2_32, winhttp, wininet и т.п.
4. Новые строки интерфейса добавляются только в `src/services/i18n.h` сразу на двух языках.
5. После изменений: собрать, запустить `finpulse_tests.exe`, проверить, что `test-results.txt` заканчивается на `0 failed`.
6. Отладка ввода: файл `debug-input.flag` рядом с exe включает журнал `debug-input.log`.
