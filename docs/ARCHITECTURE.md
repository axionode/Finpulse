# Finpulse: обзор архитектуры

Учёт личных и деловых финансов для Windows 10/11. Нативное портативное приложение (C++20 + Win32 + Direct2D): один exe, запускается без установки, полностью офлайн, файлы данных зашифрованы, тёмная тема Nordic Night, интерфейс на английском и русском.

## Как это устроено в одной картинке
```
                    Finpulse.exe (один процесс, одна копия)
 ┌──────────────────────────── UI-поток ─────────────────────────────┐
 │ platform (окно, DWM, DPI, ввод) -> ui (виджеты, графики, анимации) │
 │ screens (Старт, Пароль, Обзор, Операции, Отчёты, Настройки...)     │
 └───────────────▲──────────────────────────────┬─────────────────────┘
                 │ PostMessage(результат)        │ команды
 ┌───────────────┴────────── поток данных ───────▼─────────────────────┐
 │ services: Book / Ledger / Report / Backup / Security / Import       │
 │ domain: Money, повторы, бюджеты (без Windows)                       │
 │ storage: SQLite (sqlite3mc)   crypto: CNG, DPAPI, Argon2id          │
 └──────┬──────────────────────────┬───────────────────────────────────┘
        │                          │
  Finpulse Data\catalog.db   books\<uuid>.fpbook  (каждая книга = свой файл, ключ, валюта)
  настройки, список книг,    счета, категории, операции, бюджеты, повторы
  обёрнутые ключи
```

## Ключевые решения
| Тема | Решение | ADR |
|---|---|---|
| Язык и платформа | C++20, MSVC, Win32, статический CRT, один exe | 0001 |
| Интерфейс | Свой тулкит на Direct2D/DirectWrite/DirectComposition, рисование по требованию | 0002 |
| Внешний вид | Тёмная палитра Nordic Night, Mica на Win11, табличные цифры, свои векторные иконки, адаптивные режимы | 0003 |
| Модель | Книга -> Счета -> Операции со строками (сплиты), категории 2 уровня, переводы | 0004 |
| Хранение | SQLite, WAL, synchronous=FULL, отдельный файл на книгу, папка данных рядом с exe | 0005 |
| Деньги | int64 в минимальных единицах, одна валюта на книгу, без курсов | 0006 |
| Безопасность | PIN из 4 цифр на книгу, ChaCha20-Poly1305, ключи под Argon2id/DPAPI, автоблокировка | 0007 |
| Офлайн | Нет сетевого кода, проверка таблицы импорта при сборке, WER отключён | 0008 |
| Экспорт/импорт | Один файл .fpbackup со всеми данными и настройками, сброс PIN при импорте, автобэкапы | 0009 |
| Отчёты | 8 отчётов, все периоды, сравнения, SQL-агрегации < 50 мс на 100k | 0010 |

## Внешние зависимости
Только две, обе в исходниках внутри репозитория: SQLite3 Multiple Ciphers (MIT) и Argon2 (CC0). Остальное: Windows SDK.
