# Finpulse: функции и этапы

## Этап 1: MVP (версия 0.1 сделана 2026-11-22, кроме отмеченного ниже)
Не вошло в 0.1: архив и порядок книг перетаскиванием, массовое редактирование операций, теги, шаблоны.

**Книги**
- Создание книги: название, тип (личное, кошелёк, предприятие, проект, другое), иконка, цвет из северной палитры, валюта (одна на книгу).
- Стартовый экран с карточками книг, порядок перетаскиванием, архив книг.
- PIN из 4 цифр на книгу, автоблокировка (бездействие, Win+L, сон, Ctrl+L), задержки после неверных попыток.

**Учёт**
- Счета внутри книги (наличные, карта, банк, сбережения, кредит, долг), начальный остаток. При одном счёте слой счетов скрыт.
- Расходы, доходы, переводы между счетами, корректировка остатка.
- Разбитые операции (один чек на несколько категорий).
- Категории и подкатегории с иконками и цветами, наборы по умолчанию для личного и бизнеса (на языке интерфейса), архив и слияние категорий.
- Контрагенты с автоподстановкой категории, теги, заметки.
- Быстрое добавление с калькулятором в поле суммы, шаблоны, подсказки по последним операциям.
- Список операций: группировка по дням, итоги дня, поиск, фильтры, массовое редактирование, Корзина, Ctrl+Z.

**Отчёты**
- Обзор, по категориям с проваливанием, денежный поток, остатки во времени.
- Все периоды (день, неделя, месяц, квартал, год, произвольный, всё время), сравнение с прошлым периодом.

**Данные**
- Полный экспорт в `.fpbackup` и импорт (заменить всё / добавить книги, сброс PIN при импорте).
- Автобэкапы с ротацией.
- Режим приватности, исключение окна из захвата экрана.

**Настройки**
- Язык (English / Русский), формат чисел и дат, первый день недели, автоблокировка, папка данных и автобэкапов, ярлыки на рабочий стол и в Пуск.

**Поставка**
- Один портативный exe, запуск без установки, данные в `Finpulse Data` рядом.

## Этап 2
- Регулярные операции и плановые платежи.
- Бюджеты по категориям с прогнозом.
- Тренд категории, отчёты по контрагентам и тегам, бюджет против факта, сводный обзор по всем книгам (итоги по валютам).
- Годовой лимит дохода для книги с прогнозом.
- Экспорт одной книги, проверка файла бэкапа, напоминание об экспорте.
- Печать и PDF отчётов, графики в PNG.
- UI Automation (доступность).
- Переводы между книгами (если подтвердится, см. QUESTIONS.md).
