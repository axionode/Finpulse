# Открытые вопросы

## Решено 2026-11-22
- Мультивалютность: нет, одна валюта на книгу (ADR-0006).
- Пароль: только PIN из 4 цифр на книгу, задача защитить от постороннего за компьютером; пароля на запуск нет (ADR-0007).
- Восстановление: через экспорт/импорт бэкапа (ADR-0009).
- Поставка: портативная, запуск без установки (ADR-0005, ADR-0014).
- Языки: английский и русский (ADR-0015).
- Импорт/экспорт: только собственный формат для переезда и переустановки, без выписок и внешних сервисов (ADR-0013).
- Стиль: свой, не как MediaSense; тёмная тема в северных тонах, максимально дорого (ADR-0003).

## Осталось (у каждого есть вариант по умолчанию)
1. **Переводы между книгами** (например, из предприятия в личное, в том числе из EUR-книги в CZK-книгу с вводом суммы на каждой стороне): нужны? По умолчанию: этап 2.
2. **Пароль при экспорте бэкапа:** обязательный или по желанию с предупреждением? По умолчанию: по желанию, с предупреждением. Без пароля файл бэкапа читается любым, кто его получит, и сброс PIN через импорт тоже доступен любому.
3. **Долги** (дал/взял в долг): хватит счёта типа "долг"? По умолчанию: да.
4. **Автоблокировка:** 5 минут бездействия, при сворачивании не запирать. По умолчанию так.
5. **Годовой лимит дохода** для книги (контроль лимита паушального налога): нужен? По умолчанию: этап 2.
6. **Инструменты:** стоят ли Visual Studio 2022 или Build Tools с "Desktop development with C++" и Windows SDK? Проверю сам в начале разработки.
7. **Репозиторий:** `axionode/Finpulse`, приватный или публичный?
8. **Подпись exe:** без подписи (будет предупреждение SmartScreen при первом запуске) или сертификат? По умолчанию: без подписи.
9. **Версия Windows 10** у тебя (`winver`): от неё зависит нижняя граница поддержки. По умолчанию: 1809 и новее.
10. **Название Finpulse** окончательное? По умолчанию: да.
