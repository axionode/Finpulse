# ADR: архитектурные решения Finpulse

Здесь лежат все архитектурные решения проекта. Одно решение = один файл. Решения не переписываются задним числом: если что-то меняется, создаётся новый ADR, а старый получает статус "Заменён ADR-XXXX".

Статусы:
- Предложено: решение сформулировано, ждёт ответов из docs/QUESTIONS.md или подтверждения.
- Принято: можно реализовывать.
- Заменено / Отклонено.

Ответы на основные вопросы получены 2026-11-22, почти все решения приняты. Открытые мелочи в docs/QUESTIONS.md.
