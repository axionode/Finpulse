# ADR-0015: Языки и форматы

- Статус: Принято
- Дата: 2026-11-22

## Решение
- Языки интерфейса: **английский и русский**. При первом запуске выбирается по языку Windows (русский, украинский, белорусский -> русский, остальные -> английский), переключается в настройках без перезапуска.
- Строки в таблице, вкомпилированной в exe (UTF-16), ключ -> текст. Отсутствующий перевод = сборка падает (проверка полноты в тестах).
- Множественные формы: английский (1/many), русский (1 операция, 2 операции, 5 операций), реализованы вручную.
- Набор категорий по умолчанию создаётся на языке интерфейса в момент создания книги.
- Форматы чисел и дат через Windows NLS (`GetNumberFormatEx`, `GetDateFormatEx`, `GetLocaleInfoEx`). В настройках можно переопределить: первый день недели, формат даты, разделитель дробной части, положение символа валюты.
- В базе даты только ISO `YYYY-MM-DD`.
- Сортировка названий: `CompareStringEx`.
