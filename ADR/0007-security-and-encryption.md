# ADR-0007: Безопасность: PIN книги, шифрование, автоблокировка

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0005, ADR-0008, ADR-0009

## Контекст
Пароль только на книгу, на запуск приложения не нужен. PIN из 4 цифр достаточно. Задача PIN: не дать посмотреть книгу постороннему, который сел за компьютер. Это не сверхсекретное приложение. Восстановление при любых проблемах: через бэкап и переустановку.

## Модель угроз
| Угроза | Защита |
|---|---|
| Посторонний открыл приложение на компьютере | PIN на книгу, автоблокировка, задержки после неверных попыток |
| Посторонний смотрит на экран, демонстрация экрана | Режим приватности, исключение окна из захвата экрана |
| Файлы данных скопировали или украли ноутбук | Файлы книг зашифрованы, читать их напрямую нельзя |
| Сеть | Сети нет вообще (ADR-0008) |

Честное ограничение: 4 цифры = 10 000 вариантов. Человек за компьютером их не переберёт из-за задержек, а тот, кто унёс файл и умеет писать программы, переберёт. Для поставленной задачи это принято осознанно.

## Решение

### Пароль приложения
Нет. Приложение открывается сразу на стартовом экране со списком книг.

### PIN книги
- Ровно 4 цифры. Включается и выключается в настройках книги. При включении PIN вводится дважды.
- Смена и снятие PIN требуют ввода текущего PIN.
- Неверные попытки: после 5 подряд задержка 30 с, после следующих 3: 2 минуты, далее 5 минут. Счётчик хранится в catalog.db, перезапуск приложения его не сбрасывает.
- Стирания данных после неверных попыток нет.
- Забытый PIN: восстановление из бэкапа с паролем бэкапа и сбросом PIN (ADR-0009). Других способов сброса нет, иначе посторонний сбросит PIN тем же способом.

### Шифрование файлов
Остаётся, потому что почти ничего не стоит и закрывает случай кражи файлов.
- У каждой книги случайный ключ данных DEK 256 бит (`BCryptGenRandom`). Файл книги и журнал WAL шифруются sqlite3mc схемой ChaCha20-Poly1305.
- **Книга с PIN:** KEK = Argon2id(PIN, соль 16 байт), лёгкие параметры (64 МБ, 2 прохода, 2 потока, около 150 мс), чтобы разблокировка ощущалась мгновенной. DEK обёрнут KEK через AES-256-GCM (CNG). Правильность PIN проверяется тегом GCM, хеш PIN не хранится.
- **Книга без PIN:** DEK обёрнут DPAPI (`CryptProtectData`, текущий пользователь Windows). Открывается без вопросов.
- Обёрнутые ключи хранятся в catalog.db и копией в заголовке файла книги.

Следствие для портативности: папку с приложением можно переносить на другой компьютер, но книги без PIN откроются только у того же пользователя Windows (DPAPI). Штатный способ переезда на другой компьютер: экспорт/импорт бэкапа (ADR-0009), он работает всегда.

### Автоблокировка книги
Книга с PIN запирается:
- через N минут бездействия (по умолчанию 5, можно 1-60 или выключить);
- при блокировке Windows (Win+L) и смене пользователя (`WTSRegisterSessionNotification`);
- при уходе в сон;
- при сворачивании окна (опция, по умолчанию выключено);
- вручную Ctrl+L или кнопкой замка.

При запирании соединение с базой закрывается, ключ затирается, данные книги выгружаются из памяти, показывается экран PIN.

### Гигиена
- Ключи в буферах `VirtualLock`, затираются `SecureZeroMemory`.
- Отчёты об ошибках Windows для процесса отключены (`WerAddExcludedApplication`).
- Журнал без сумм, названий и PIN.
- Исключение окна из скриншотов и записи экрана: опция (`WDA_EXCLUDEFROMCAPTURE`).
- Режим приватности: скрыть суммы.

## Отклонено
- Пароль приложения, код восстановления, усиленный режим с привязкой к Windows, Windows Hello, длинные пароли: избыточно для задачи.

## Последствия
Простой и быстрый вход по PIN, разблокировка без ощутимой задержки, файлы на диске всё равно не читаются напрямую.
