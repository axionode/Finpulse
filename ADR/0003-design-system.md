# ADR-0003: Дизайн-система "Nordic Night"

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0002

## Контекст
Главное требование: максимально красиво и дорого, только тёмная тема, оттенки в духе нордик. Единый стиль с MediaSense не нужен.

"Дорого" здесь значит: сдержанная палитра, много воздуха, тонкие линии вместо рамок, крупные цифры лёгкого начертания, акцент используется редко и точно, никакой пестроты.

## Решение

### Палитра
Основа: холодные сине-серые тона северной ночи, глубже классической палитры Nord (у неё фон светловат для "дорогого" вида). Акценты: ледяные (frost) и приглушённые цвета северного сияния (aurora).

**Поверхности (от глубины к верху)**
| Токен | Цвет | Назначение |
|---|---|---|
| night-0 | #0F1217 | фон окна (на Win11 под ним Mica с тёмной тонировкой) |
| night-1 | #151920 | основная поверхность, боковое меню |
| night-2 | #1B2029 | карточки |
| night-3 | #232937 | поля ввода, наведение, выделенная строка |
| night-4 | #2C3444 | всплывающие меню, диалоги |
| hairline | #D8DEE9 при 7% | разделители и контуры карточек толщиной 1 px |

**Текст**
| Токен | Цвет | Назначение |
|---|---|---|
| snow-1 | #ECEFF4 | основной текст, крупные суммы |
| snow-2 | #A9B2C3 | вторичный текст |
| snow-3 | #6B7487 | подписи, плейсхолдеры, неактивное |

**Акценты**
| Токен | Цвет | Назначение |
|---|---|---|
| frost | #88C0D0 | основной акцент: фокус, активный пункт меню, главная кнопка |
| frost-deep | #5E81AC | нажатие, выделение текста, линии графиков |
| income | #A3BE8C | доходы |
| expense | #D9828A | расходы (смягчённый красный, не кричит) |
| transfer | #81A1C1 | переводы |
| warning | #EBCB8B | бюджет почти исчерпан |
| purple | #B48EAD | дополнительный цвет категорий |
| orange | #D08770 | дополнительный цвет категорий |

Контраст основного и вторичного текста на night-1/night-2 не ниже 7:1, подписей не ниже 3:1.

**Цвета книг и категорий**: не свободная палитра, а подобранный набор из 16 приглушённых северных оттенков (frost, aurora и их тёмные/светлые варианты). Любые комбинации выглядят цельно. Цвет книги подкрашивает тонкую полосу в шапке, кольцо иконки и основную серию графиков этой книги.

### Типографика
- Win11: Segoe UI Variable (Display для крупных цифр, Text для остального). Win10: Segoe UI.
- Крупная сумма на обзоре: 40 px, начертание Light (300). Заголовки экранов: 20 px Semibold. Основной текст: 14 px Regular. Подписи: 12 px, разреженные на 2%, верхний регистр только для подписей секций.
- Все суммы с табличными цифрами (OpenType `tnum`), чтобы столбцы выравнивались. Копейки/центы выводятся на ступень мельче и цветом snow-2: "12 480,50" читается быстрее.
- Знак у сумм: расход без минуса, но цветом expense и иконкой направления; доход со знаком "+".

### Формы и детали
- Сетка 4 px. Отступы 8/12/16/24/32. Внутри карточек минимум 20 px воздуха.
- Радиусы: 6 (поля, кнопки), 12 (карточки), 16 (диалоги).
- Рамки вместо теней: карточки отделяются оттенком поверхности и hairline. Тень только у всплывающих элементов, мягкая и тёмная.
- Иконки: свой векторный набор, линия 1.5 px, скруглённые окончания, единый стиль. Иконка категории в круге с заливкой цвета категории при 16% и самой иконкой в полном цвете. Эмодзи не используем: они ломают сдержанный стиль.
- Графики: тонкие линии 1.5 px со сглаживанием, мягкий вертикальный градиент под линией (цвет при 20% -> 0%), столбцы со скруглённым верхом, кольцевая диаграмма с зазорами 2 px между сегментами и суммой в центре. Сетка графиков едва видна (hairline).

### Движение
120-220 мс, ease-out (cubic-bezier 0.2, 0, 0, 1). Анимируются: появление диалогов (сдвиг 8 px + прозрачность), смена периода (горизонтальный сдвиг содержимого), рост столбцов и сегментов, плавный пересчёт крупной суммы. Наведение: смена фона за 80 мс. Если в Windows отключены анимации, всё мгновенно.

### Окно
- Свой заголовок в цвет night-0, без системной полосы. Тёмная рамка через DWM, скругления на Win11.
- Mica на Win11 22H2+ (тонированный тёмный), на Win10 сплошной night-0.

### Адаптивность
- < 720 px: боковое меню сворачивается в иконки, карточки в одну колонку.
- 720-1200 px: обычный режим.
- > 1200 px: обзор в две колонки, отчёт и список операций рядом.
- Минимум 480x600. Размер и положение окна запоминаются.

### Экраны
1. **Стартовый:** карточки книг (иконка, название, тип, валюта, баланс; у книги с PIN вместо баланса замок). Кнопки "Новая книга", "Импорт", "Настройки".
2. **PIN:** четыре точки, цифровой блок для мыши, ввод с клавиатуры, мягкое покачивание точек при ошибке, таймер задержки после неверных попыток.
3. **Книга:** боковое меню (Обзор, Операции, Счета, Категории, Бюджеты, Отчёты, Регулярные, Настройки книги).
4. **Быстрое добавление** (Ctrl+N или "+"): крупное поле суммы с калькулятором, сетка категорий, счёт, дата, заметка. Enter сохраняет, Ctrl+Enter сохраняет и открывает следующую.

### Горячие клавиши
Ctrl+N расход, Ctrl+I доход, Ctrl+T перевод, Ctrl+F поиск, Ctrl+Z / Ctrl+Y отмена/повтор, Ctrl+L запереть книгу, Alt+стрелки предыдущий/следующий период, F1 список клавиш.

### Режим приватности
Кнопка "глаз" заменяет все суммы на •••.

## Последствия
Только тёмная тема, светлая не планируется. Все цвета идут через токены, правка палитры в одном месте. Перед началом вёрстки делается макет 3 ключевых экранов (старт, обзор, быстрое добавление) для утверждения вида.
