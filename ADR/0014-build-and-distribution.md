# ADR-0014: Сборка, установка, обновления

- Статус: Принято
- Дата: 2026-11-22

## Решение
**Сборка:** CMake + Ninja + MSVC (всё входит в VS 2022 Build Tools). Один скрипт `build.cmd` (Debug/Release), `test.cmd`, `bench.cmd`. Проверка импортов (ADR-0008) встроена в сборку как пост-шаг. Ресурсы (иконка, манифест, версия) через `.rc`.

**Манифест:** Per-Monitor V2 DPI, `longPathAware`, supportedOS Win10/11, Common Controls v6 (для системных диалогов), `activeCodePage UTF-8`.

**Дистрибуция:** только портативный вариант. Один `Finpulse.exe`, кладётся в любую папку и сразу запускается, установка не нужна. Рядом при первом запуске создаётся `Finpulse Data` (ADR-0005). В настройках есть кнопки "Ярлык на рабочий стол" и "Ярлык в меню Пуск" (`IShellLink`), без записей в реестр. Удаление приложения = удаление папки.

**Обновления:** только вручную, заменой exe в той же папке. Миграции данных выполняются локально при первом запуске новой версии с автобэкапом перед миграцией.

**Подпись кода:** неподписанный exe вызывает предупреждение SmartScreen и иногда ложные срабатывания антивирусов. Варианты: оставить без подписи (для личного использования нормально), купить сертификат или использовать облачную подпись. Под вопросом.

**Репозиторий:** README с инструкцией по сборке для человека и отдельный раздел для ИИ-агента (как в MediaSense): какие инструменты нужны, как проверить их наличие, команды сборки и тестов.
