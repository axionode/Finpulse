# ADR-0012: Слои приложения, потоки, состояние, отмена действий

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0002, ADR-0005

## Решение

### Слои (зависимости только сверху вниз)
```
app/        точка входа, цикл сообщений, сборка зависимостей
platform/   окно, DPI, ввод, D3D/D2D/DComp, DWM, файловые диалоги, буфер обмена
ui/         тулкит: виджеты, раскладка, анимации, тема, иконки
screens/    экраны и модели представления (ViewModel)
services/   BookService, LedgerService, ReportService, BackupService, SecurityService
domain/     чистый C++: Money, справочник валют, правила повторов, расчёт бюджетов, парсер выражений
storage/    SQLite-репозитории, миграции, схема
crypto/     обёртки CNG, DPAPI, Argon2, SecretBuffer
i18n/       строки, форматы
```
`domain/` не зависит от Windows вообще, поэтому полностью покрывается модульными тестами.

### Потоки
- **UI-поток:** цикл сообщений, раскладка, рендеринг. Никогда не ждёт диск и никогда не выполняет тяжёлых вычислений.
- **Поток данных (один):** владеет всеми соединениями SQLite, выполняет запросы, Argon2, экспорт и импорт бэкапов. Принимает команды из очереди, результат возвращает в UI через `PostMessage(WM_APP_RESULT)`.
- Больше потоков не создаём. Argon2 внутри использует свои 4 потока только на время вывода ключа.

### Поток состояния (однонаправленный)
Действие пользователя -> команда в сервис -> поток данных -> событие "данные изменились" -> ViewModel обновляется -> invalidate -> перерисовка только изменённой области.

### Отмена действий
- Каждое изменение данных оформлено командой с обратной операцией. Ctrl+Z / Ctrl+Y в пределах сессии работы с книгой.
- Удалённые операции попадают в Корзину на 30 дней (deleted_at), восстанавливаются оттуда.

### Ошибки и журнал
- `Result<T, Error>` во всех слоях, исключения не используются.
- Журнал локальный, ротация по размеру, без сумм, названий и паролей. Уровень подробности в настройках.

### Запуск (цель)
Процесс стартует -> окно с фоном (до 50 мс) -> catalog.db -> стартовый экран (до 250 мс на i7-6700HQ). Тяжёлое (калибровка Argon2, проверка целостности) откладывается.
