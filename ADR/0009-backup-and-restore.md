# ADR-0009: Экспорт и импорт (бэкап и восстановление)

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0005, ADR-0007

## Контекст
Импорт и экспорт нужны только внутри приложения: переезд на другой компьютер, переустановка, страховка. Никаких банковских выписок и внешних сервисов. После импорта всё должно работать точно так же, включая настройки.

## Решение

### Полный экспорт: файл `.fpbackup`
Меню "Экспорт всех данных". Внутри:
- настройки приложения (язык, формат, автоблокировка, размеры окна, папка автобэкапов);
- все книги со всеми счетами, категориями, операциями, бюджетами, правилами повторов, шаблонами, настройками книг (цвет, иконка, валюта, PIN);
- манифест: версия формата, версия приложения, версии схем, дата, SHA-256 каждого элемента.

Снимок книг согласованный (SQLite Online Backup API), работу останавливать не нужно.

### Пароль бэкапа
- При экспорте предлагается задать пароль бэкапа (рекомендуется). Тогда файл шифруется: Argon2id -> ключ 256 бит -> AES-256-GCM (CNG) блоками по 1 МБ, в AAD номер блока и флаг последнего блока. Обрезанный или изменённый файл распознаётся.
- Можно экспортировать без пароля: тогда показывается предупреждение, что файл читается любым, кто его получит.
- Внутри бэкапа ключи всех книг переобёрнуты ключом бэкапа (DPAPI на другом компьютере не работает, а PIN не должен быть единственным замком в бэкапе).

### Импорт
- На стартовом экране кнопка "Импорт". Выбор файла -> пароль бэкапа (если задан) -> предпросмотр: список книг, число операций, дата бэкапа.
- Режимы: "Заменить всё" (перед этим автоматически сохраняется снимок текущих данных) или "Добавить книги" (если такая книга уже есть: заменить / оставить обе / пропустить).
- PIN книг переносятся как были. На шаге предпросмотра можно отметить "Сбросить PIN у книг". Это и есть способ восстановления при забытом PIN: владение бэкапом и его паролем подтверждает право.
- Новая версия приложения читает бэкапы всех старых версий. Старая версия на бэкап новее себя отвечает понятным сообщением.

### Экспорт одной книги
Тот же формат, но с одной книгой. Удобно для передачи или отдельного архива.

### Автобэкапы
- При закрытии приложения и раз в сутки, если были изменения. Ротация: 7 ежедневных, 4 еженедельных, 12 ежемесячных.
- Папка по умолчанию `Finpulse Data\Backups` рядом с данными, можно указать другой диск или флешку.
- Шифруются паролем автобэкапа, если он задан в настройках (хранится обёрнутым DPAPI, чтобы не спрашивать каждый раз). Без пароля автобэкап содержит файлы книг как есть, восстанавливается только на этом компьютере. Об этом подсказка в настройках.

### Проверка и напоминания
- "Проверить файл бэкапа": расшифровка и сверка контрольных сумм без импорта.
- Напоминание, если полного экспорта не было больше 30 дней (можно выключить).

### Формат
Свой контейнер TLV (тип, имя, размер, данные), без zip-библиотек. Открытый заголовок: магия `FPBK`, версия формата, флаг шифрования, параметры KDF, соль. Названий книг в открытом виде нет.

## Последствия
Переезд на другой компьютер: скопировать папку с exe (или только exe), нажать "Импорт", выбрать файл, ввести пароль. Парсер бэкапа обязательно фаззится (ADR-0016), так как это внешний вход.
