# ADR-0010: Отчёты и аналитика

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0006, ADR-0012

## Контекст
Отчёты по всем периодам, удобно смотреть, красиво, быстро на больших объёмах.

## Решение

**Периоды:** день, неделя (первый день недели по настройке), месяц, квартал, год, произвольный диапазон, всё время. Переключение стрелками и Alt+стрелки, свайпом на тачпаде. Сравнение с предыдущим периодом и с тем же периодом прошлого года (+12% / -8%).

**Отчёты**
1. Обзор книги: доходы, расходы, результат, норма сбережений, остатки по счетам, ближайшие плановые платежи, бюджеты с прогрессом.
2. По категориям: кольцевая диаграмма + список с долями и суммами. Клик проваливает в подкатегории, затем в список операций.
3. Денежный поток: столбцы доход/расход по дням/неделям/месяцам, линия результата.
4. Остатки во времени: линия по каждому счёту и общая.
5. Тренд категории: 12 месяцев, среднее, минимум, максимум.
6. По контрагентам и по тегам.
7. Бюджет против факта.
8. Сводный по всем открытым книгам: итоги сгруппированы по валютам (CZK отдельно, EUR отдельно), разные валюты не складываются. Запертые книги не участвуют, это видно в отчёте.
9. Годовой лимит (опция книги): доходы нарастающим итогом за календарный год против заданной суммы, прогноз выхода за лимит. Полезно, например, для лимита дохода при паушальном налоге. Этап 2.

**Фильтры:** счета, категории, теги, контрагенты, диапазон сумм, текст (FTS5), статус. Фильтры можно сохранять.

**Движок:**
- Агрегации на SQL по индексам, результат в лёгкие структуры для графиков.
- Цель: любой отчёт по 100 000 операций быстрее 50 мс на i7-6700HQ.
- Если замеры покажут, что не укладываемся, добавляется таблица помесячных агрегатов, обновляемая в той же транзакции, что и операция. Только по результатам бенчмарка, не заранее.
- Запросы выполняются в потоке данных (ADR-0012), UI не блокируется; смена периода анимируется.

**Вывод отчётов:** график в PNG (WIC), экспорт таблицы в CSV на этапе 3 (ADR-0013). Печать/PDF через системный принтер "Microsoft Print to PDF" (`ID2D1PrintControl`): этап 2.

## Последствия
Графики свои на Direct2D, без библиотек. Набор из 8 отчётов покрывает и личный учёт, и малый бизнес.
