# ADR-0013: Импорт и экспорт во внешние форматы

- Статус: Принято
- Дата: 2026-11-22
- Связано с: ADR-0009

## Решение
- Импорт банковских выписок, CSV-импорт, импорт из Spendee и любых внешних сервисов: **не делаем**.
- Импорт и экспорт данных только в собственном формате `.fpbackup` (ADR-0009).
- Экспорт отчёта или списка операций в CSV: низкий приоритет, этап 3, только если понадобится открыть данные в Excel.
